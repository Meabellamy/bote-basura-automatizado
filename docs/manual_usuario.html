Manual de Usuario — Bote de Basura Automatizado Sección 1 · Introducción y materiales

1. ¿Qué es y cómo funciona?

💡 En una frase Acerca la mano al sensor → la tapa se abre sola → deposita la basura → la tapa se cierra a los 3 segundos. Sin tocar nada.

El bote tiene un pequeño sensor invisible al frente. Cuando detecta tu mano a menos de 20 cm, manda una señal a un motorecillo que levanta la tapa. No importa si llevas las manos sucias o llenas — nunca necesitas tocar el bote.

2. Lo que necesitas

🟧 Arduino UNO
El cerebro del sistema. Se conecta a la PC solo para programarlo — una sola vez.
🟨 Sensor HC-SR04
El "ojo" del bote. Mide distancias con ultrasonido, como los sensores de reversa de un carro.
🟥 Servomotor SG-90
El músculo. Un motor pequeño que gira exactamente los grados necesarios para abrir y cerrar la tapa.
🟩 Cables Dupont
Los que conectan todo. Son enchufables — no se necesita soldar nada.
⚡
Alimentación El sistema funciona con el cable USB del Arduino enchufado a cualquier cargador de celular (5 V) o a una power bank. No necesita baterías especiales ni fuente de voltaje extra.

4. Cargar el programa (una sola vez)

Esto se hace una única vez. Después el bote funciona solo cada vez que lo enchufas.

1
Descarga el IDE de Arduino Entra a arduino.cc/en/software e instala el programa gratuito. Elige la versión para tu sistema operativo.
2
Abre el archivo del proyecto Ve a la carpeta src/ y abre el archivo bote_basura.ino con el IDE de Arduino.
3
Conecta el Arduino por USB Usa el cable USB que viene con el Arduino. La computadora lo reconocerá automáticamente.
4
Selecciona la placa y el puerto En el IDE: Herramientas → Placa → Arduino UNO y luego Herramientas → Puerto → COM# (el que aparezca).
5
Presiona el botón "Subir" → Es la flecha apuntando a la derecha en la barra superior. Espera unos segundos hasta que aparezca "Carga completa". ¡Listo! El Arduino ya tiene el programa.
✅ ¿Cómo sé que funcionó? En cuanto termine la carga, el servo se mueve brevemente a la posición de cerrado. Eso confirma que el programa está corriendo.

5. Cómo usar el bote

🖐️
Acerca la mano
Pon la mano frente al sensor a menos de 20 cm. No necesitas tocar nada.
🔓
La tapa se abre
El servo gira y levanta la tapa automáticamente en menos de 1 segundo.
🗑️
Tira la basura
Tienes 3 segundos para depositar lo que necesitas. La tapa se mantiene abierta.
🔒
Cierre automático
Sin hacer nada, la tapa se cierra sola a los 3 segundos. El bote queda listo.
💡
Tip de uso Si necesitas más tiempo con la tapa abierta — por ejemplo para vaciar un recipiente grande — puedes mantener la mano frente al sensor. Mientras detecte proximidad, el ciclo se reinicia.

6. Algo no funciona — Solución rápida

SíntomaCausa probableSolución
🔴 La tapa no abre aunque acerco la mano Mano muy lejos o cable TRIG/ECHO suelto Acércate a menos de 20 cm · Revisa que D9→TRIG y D10→ECHO estén bien conectados
🟡 La tapa abre y cierra sola sin que nadie se acerque El sensor está viendo un objeto fijo cercano (pared, mueble) Reubica el bote para que no haya obstáculos a menos de 20 cm frente al sensor
🟠 El servo vibra o tiembla pero no gira bien Falta de corriente — el USB no da suficiente amperaje Usa un cargador de al menos 1 A, o alimenta el servo con fuente externa de 5 V compartiendo GND
⚫ No pasa nada al enchufar el USB El programa no está cargado o el Arduino no tiene energía Verifica que el LED verde del Arduino enciende · Repite el paso de carga del programa
🔵 La tapa abre pero no cierra El servo está físicamente bloqueado Verifica que la tapa no esté atorada mecánicamente y que el brazo del servo tenga libertad de movimiento
🟣 El IDE no detecta el Arduino (sin puerto COM) Falta el driver CH340 o cable USB solo de carga Instala el driver CH340 desde internet · Usa un cable USB con datos (no solo carga)

7. Mantenimiento

✔
Limpia el sensor periódicamente El HC-SR04 tiene dos "ojos" redondos de aluminio. Si se acumula polvo o suciedad encima, la detección falla. Límpialo con un paño seco cada 2 semanas.
✔
Revisa las conexiones si el bote deja de responder Los cables Dupont pueden aflojarse con el uso. Desenchufa el USB, revisa que todos los cables estén bien insertados y vuelve a enchufar.
✔
No mojes el circuito Los componentes no son resistentes al agua. Mantén el bote alejado de líquidos. Si necesitas limpiarlo, desenchufa el USB primero.
